插件
用你已有的订阅给 agent 提供模型

插件帮 morula 接入其他订阅：登录、选模型、看额度。

  1. 在下面挑一个插件，点「安装」
  2. 到「账号」登录这个订阅
  3. 在 Agent 页或对话框里选它的模型

插件是第三方写的代码，以你的身份运行在本机，装之前先看它的主页和说明。经第三方调用订阅可能违反厂商条款，账号有被封的风险。

精选订阅
