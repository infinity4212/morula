# 图标出处

本目录的 SVG 取自 lobe-icons（https://github.com/lobehub/lobe-icons ，MIT 许可），
用的是 npm 包 `@lobehub/icons-static-svg` 1.95.1 的 `icons/` 目录，2026-10-18 下载。拷贝时去掉了根元素的宽、高和 style。

文件名不带 `-color` 的是单色图标，界面用 CSS mask 按文字颜色画；带 `-color` 的按原色显示。
harness 用哪个图标写在 `../app.js` 的 `HZ_ICONS`，插件包用哪个图标写在 `../picks.json`。
